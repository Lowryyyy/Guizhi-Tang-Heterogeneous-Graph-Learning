# How this folder is uploaded to GitHub

1. Create a new **Public** repository named
   `Guizhi-Tang-Heterogeneous-Graph-Learning` at https://github.com/new
   (do **not** initialise it with a README).
2. Open this folder in File Explorer, select all contents (Ctrl+A), drag them into
   **Add file -> Upload files** on the new repository page, then **Commit changes**.
3. Create the tag used by the manuscript: repository page -> **Releases** ->
   **Create a new release** -> **Choose a tag** -> type `v2.0-revision` ->
   **Create new tag on publish** -> target `main` -> **Publish release**.
4. Verify https://github.com/Lowryyyy/Guizhi-Tang-Heterogeneous-Graph-Learning/tags
   shows `v2.0-revision`.

If a different repository name is used, update the URL in the manuscript Code Availability,
the response letter and `CITATION.cff`/`zenodo_metadata.json` before submission
(the submission package provides `set_github_repo.py` for this).
