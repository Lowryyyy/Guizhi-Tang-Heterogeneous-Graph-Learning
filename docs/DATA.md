# Data provenance (revision v2.0)

All analyses use publicly available data. Access dates refer to the revision performed in October
2026. Files under `data/raw/` are either downloaded records or curated tables assembled from the
sources listed below; the processing code is in `src/`.

## Knowledge graph inputs

| File | Content | Source | Notes |
|------|---------|--------|-------|
| `guizhi_tang_compounds.json` | 86 herb-compound records (77 unique compounds) with OB and DL values | TCMSP (https://tcmsp-e.com/) | Five herbs: Guizhi, Baishao, Shengjiang, Dazao, Gancao. 68 compounds meet OB>=30% and DL>=0.18; nine documented constituents below DL were retained and flagged in the manuscript. |
| `compound_target_interactions.json` | 403 compound-target edges; 46 target annotations | TCMSP target records supplemented with SwissTargetPrediction (https://www.swisstargetprediction.ch/) and UniProt gene symbols | Predicted interactions; not all are experimentally confirmed. |
| `target_disease_associations.json` | 31 diseases, 415 target-disease edges, 30 DrugBank drugs, 154 known compound-disease links | DisGeNET (GDA score >= 0.1), OMIM, DrugBank, literature curation | Disease and compound-disease layers mix curated and inferred associations; see manuscript limitations. |
| `string_ppi_real.json` | STRING v12.0 interactions (combined score >= 400) among the 47 targets | STRING (https://string-db.org/) | 198 interactions within the target set; replaces the hard-coded list of the original submission. |
| `drug_indications_chembl.json` | Approved-drug indications | ChEMBL (https://www.ebi.ac.uk/chembl/) | 29 drugs; 162 drug-disease edges matched to the 31 disease nodes by exact MeSH/EFO term. Replaces synthetic edges inferred from shared targets. |
| `kegg_hsa_gene_pathway_links.json` | 39,671 KEGG human gene-pathway links | KEGG REST (https://rest.kegg.jp/link/pathway/hsa) | Background: 9,451 genes. |
| `kegg_hsa_pathway_names.json` | 372 KEGG human pathway names | KEGG REST (https://rest.kegg.jp/list/pathway/hsa) | |
| `kegg_symbol_to_geneid.json` | KEGG gene symbol to NCBI gene ID map | KEGG REST (https://rest.kegg.jp/list/hsa) | Used to map the 47 target symbols to KEGG gene IDs. |

## Docking inputs

Protein structures were downloaded from the RCSB PDB (https://www.rcsb.org/): 4EKL (AKT1), 4LVT
(BCL2), 1NME (CASP3), 1HCK (CDK2), 1Y57 (SRC), 5KIR (PTGS2), 2AZ5 (TNF), 5P21 (HRAS), 1QIB (MMP2).
Ligand 3D conformers were downloaded from PubChem (https://pubchem.ncbi.nlm.nih.gov/). AutoDock Vina
1.2.7 (https://github.com/ccsb-scripps/AutoDock-Vina) was used with exhaustiveness 16 (predicted
pairs) / 8 (decoys) and random seed 42; every grid box is listed in Table 5 of the manuscript and in
Supplementary Table S5. Grid centres were obtained from the co-crystallised ligand (AKT1, BCL2,
CASP3, SRC, PTGS2, TNF), the ATP ligand (CDK2), the GppNHp ligand (HRAS) or the catalytic zinc
(MMP2).

## Processed data

`data/processed/graph_data.json` contains the deterministic node order, node features, all typed
edges, the 154 supervision labels and the graph statistics. `data/processed/graph_statistics.json`
summarises node and edge counts. These files are generated by `src/graph_builder.py`.
